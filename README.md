# lms_video_player
Video Player — минималистичный видеоплеер с базой данных
Это десктопное приложение на Python (PyQt6 + SQLite) для просмотра видео с сохранением позиции воспроизведения.

Основные возможности
	Просмотр видео с полосой прогресса, кнопками паузы/продолжения и перемоткой на 10 секунд стрелками.
	Сохранение позиции: при закрытии окна текущая отметка времени записывается в базу данных; при следующем запуске видео стартует с этого места.
	Сброс позиции до начала, если видео досмотрено до конца.
	Управление коллекцией: добавление новых видео (копирование в папку videos), фильтрация по названию, удаление (с очисткой файла с диска).
	Кастомный интерфейс: без стандартных рамок ОС, со скруглёнными углами, кастомной панелью заголовка, возможностью растягивания и сворачивания.
	Уведомления: всплывающие плашки-подсказки (toast) о результатах действий.
Особенности реализации
	Стек: Python 3, PyQt6 (QMediaPlayer + QVideoWidget), SQLite.
	Медиа‑бэкенд: FFmpeg (задаётся через QT_MEDIA_BACKEND).
	Хранение данных: все сведения о видео (название, путь, текущая позиция) хранятся в SQLite‑базе.
	Структура файлов: видеофайлы лежат в папке videos, иконки — в папке icons
